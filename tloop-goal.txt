GOAL: Every 2 minutes, one screenshot checks whether Roblox is still IN GAME.
If it IS IN GAME -> return done (the system will keep clicking the middle of the Roblox window and pressing T).
Otherwise -> do not spam. Handle the state below. Do NOT stop the program, and do not decide from a single unclear image.

STATE 1 - IN GAME (world, character, HP, Level, or game chat is visible, not the Roblox menu or home screen):
  -> return ONLY: [{"action":"done","reason":"in game"}]
  (done means "still in game" for the system. It does NOT stop the program.)

STATE 2 - LOADING (Roblox is loading and the world is not clear yet):
  -> [{"action":"wait","ms":3000}]

STATE 3 - ON THE ROBLOX MENU OR HOME (not a kick, not an error dialog):
  Prefer the CONTINUE row to rejoin:
  1. Find "Continue" / the game just played on the Roblox menu (usually at the top, cover art plus the game name).
  2. The most recent game is the first Continue row. If the cover or name is clear, choose it.
  3. Click its Play/Continue button: [{"action":"click","x":...,"y":...}] -> [{"action":"wait","ms":3000}]
  4. If Continue is missing, the position is unclear, or the click left you on the menu, run bash:
     powershell -NoProfile -ExecutionPolicy Bypass -File "D:\computer use\tloop-relaunch.ps1"
     then return: [{"action":"wait","ms":3000}]
  IF the image path says "do NOT run tloop-relaunch.ps1 again" -> use only steps 1-3 (Continue). Do NOT run the ps1.

STATE 4 - KICKED / ERROR DIALOG / ROBLOX ERROR (an error message, disconnected from the server, or Roblox Error):
  - Run bash FIRST: powershell -NoProfile -ExecutionPolicy Bypass -File "D:\computer use\tloop-relaunch.ps1"
    (it reads the last placeId from the log, closes the old Roblox, and reopens it through the Froststrap protocol.)
  - Then return: [{"action":"wait","ms":3000}]

STATE 5 - NO ROBLOX WINDOW (crashed or closed):
  - Run bash: powershell -NoProfile -ExecutionPolicy Bypass -File "D:\computer use\tloop-relaunch.ps1"
  - Return: [{"action":"wait","ms":3000}]

RULES:
- BEFORE deciding any state: if another window covers the screen or Roblox is not clearly visible,
  first run [{"action":"window_activate","target":"Roblox"}] and return [{"action":"wait","ms":1500}].
  Decide only when the Roblox screen is clearly visible.
- Click only when Roblox is in the foreground and the image is clear. Coordinates come from the screenshot, not a guess.
- Use "done" ONLY for state 1. Using it for another state cancels the spam.
- Run tloop-relaunch.ps1 only when state 4 or 5 asks for it (or state 3 after the four steps fail).
  When the screen already says "do NOT run it again", do not run the ps1.
- Return ONLY one JSON array, at most 5 actions, with no other text or markdown.
- If it is unclear: [{"action":"wait","ms":2000}].
