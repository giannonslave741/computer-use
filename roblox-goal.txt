GOAL: Switch to the Roblox window, join any game, then move the character.

STEP 1 - BRING THE ROBLOX WINDOW TO THE FRONT (do this BEFORE any other action):
- If the current shot does not clearly show Roblox (a terminal window covers it), run bash first:
  powershell -NoProfile -Command (New-Object -ComObject WScript.Shell).AppActivate('Roblox')
  then return [{"action":"wait","ms":1500}]. The next cycle captures again.
- If it is still unclear: click the Roblox icon on the taskbar to fill the screen.
- Only give other actions when the Roblox screen is fully visible.

STEP 2 - JOIN A GAME (if you are on the Roblox home, menu, or lobby):
- Click any game tile visible on screen, then click Play or Join.
- If a confirm or notice dialog appears, click OK or close it.
- Wait with a 1500ms wait action, and repeat until the game world is visible (HP/Level bar, or the character).

STEP 3 - MOVE THE CHARACTER:
- Once the character or the game world is visible, return this chain:
  [{"action":"hold","key":"W","ms":1500},{"action":"wait","ms":300},{"action":"hold","key":"A","ms":700}]
- Then capture again to see whether the character moved.
- If a menu or dialog blocked the move: click the middle of the game, then repeat the hold chain.
- When the character has moved (the in-game position changed): return [{"action":"done","reason":"character moved"}].

RULES:
- NEVER click at x <= 10 and y <= 10 (the top-left corner). That corner is the emergency stop.
- Return ONLY one JSON array that starts with [ and ends with ]. No other text and no markdown.
- If it is unclear: [{"action":"wait","ms":1500}].
- At most 5 actions per response.
